# 首页提醒、师生沟通与主题更新

更新日期：2026-10-02。

学生首页增加每日词汇提醒，显示待复习旧词、待学新词和今日已完成词数，并提供进入词汇学习的按钮。提醒独立于当天作业列表，没有作业时也会显示。已开始但尚未完成的词会计入待背数量，不会重复计算为新增计划；页面打开时及重新回到页面时会更新，显示期间每 30 秒更新一次。

教师词汇页面的每日新词数量可设为 0–1000。前端输入与服务端校验均已同步。0 表示暂停新增词汇，已开始的练习和到期旧词保留。

师生双方首页增加“师生留言板”，原有老师通知板继续用于教学通知。学生可以说明任务无法完成的情况或提出问题，老师可回复。留言保存在 SQLite 中，显示发送人、时间、未读数量和对方已读状态；最新留言在前，支持查看更早记录。对方需要点击“将当前留言标为已读”确认查看。单条留言限 2000 字。页面打开及获得焦点时刷新，显示期间每 30 秒更新，隐藏时暂停请求。

留言接口由登录账号确定发送人及所属师生关系，客户端不能指定身份或收件人。启动应用时会自动执行 `0008_messages.sql`，建立留言表，保留旧数据。

主题统一使用根节点的 `.dark` 状态，组件样式、图表色板和侧边栏不再各自使用系统主题。知识拓展内嵌页面直接更新主题，不再在切换时重建正文。切换按钮触发 220 毫秒颜色过渡，遵循系统“减少动态效果”设置；补齐了学生周回顾、空状态和选中标签的夜间颜色。

验证使用隔离的测试数据。已在 390px 与 320px 宽度检查学生提醒、留言发送、教师回复和 1000 词设置；通过浏览器实测确认日夜颜色即时更新和内嵌正文变色。自动测试覆盖提醒计数、角色权限、非法上限、请求来源、空留言、身份伪造防护、已读状态和历史分页。未进行真机软键盘或 Safari 兼容性测试，未部署。
