## 关于图片

互动页面在沙箱里运行，不能联网（国内网络也常打不开 Wikimedia 等图库），所以这批页面的“图片”全部是**原创内联 SVG 插画、CSS 图形和 emoji**，打开即显示、不会裂图。没有使用真实照片、电影截图、球队或汽车商标。

如需真实照片（例如 NASA 的阿波罗照片属公有领域），按规范上传到“页面媒体”后用 `data-media` 或 `ED.media()` 引用。披头士页已经预留了 `song-clip` 音频位：上传后自动出现，没上传时隐藏。

## 评测时可以重点比较

1. **版式**：纵向长页（01/02/09/10）、翻页书（03）、分幕舞台（04）、游戏地图入口（08）、进度驱动（05/11）——学生更愿意做完哪一种？
2. **游戏化程度**：计分、集糖果、火箭进度（05/08/11）是否提升完成率？会不会喧宾夺主？
3. **视觉密度**：安静克制（10）和高饱和热闹（02/07）各自适合哪类主题？
4. **活动数量**：目前每页 5–8 个 `ED.done` 活动，规范建议 3–5 个，可以据此确定上限。
5. **中文支架**：每节一行中文提示，阅读段落点词看中文——是否够用、是否过多？
6. **夜间模式与手机**：每页都已在 390px 宽度和 `html.dark` 下截图检查过，没有横向滚动。
