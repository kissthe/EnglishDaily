# 用英语探索世界：第一轮六个主题

面向 A2–B1 学习者，每课约 20–30 分钟。每页固定使用“一个引导问题 → 背景事实 → 短篇英文 → 词汇与文化 → 理解检测 → 个人表达”。先帮助学生理解内容，再要求输出；不要求背百科或逐句翻译。

| 主题 | 核心问题 | HTML 展示设计 | 语言目标与产出 |
|---|---|---|---|
| California & Los Angeles | California 和 LA 是同一级地名吗？ | 国家—州—城市层级图；海岸、城市、电影工业三张事实卡；LA / Los Angeles 名称对照 | state / city / coast / neighborhood；用四句话介绍一个地方 |
| London: A City on the River | 泰晤士河怎样串起伦敦？ | 河流与地标示意图（标明非比例地图）；Westminster、Tower Bridge、博物馆三站路线 | across / next to / along；为同伴设计半日路线并说明理由 |
| The Wizard of Oz | Dorothy 真正想寻找什么？ | 人物关系卡；开端—旅程—选择的故事时间轴；折叠的情节提示 | character / journey / courage / home；用自己的话概括人物愿望，避免整段抄台词 |
| The Sound of Music | 一部音乐电影怎样讲家庭与勇气？ | 电影与真实历史分栏；Austria 背景卡；场景观察任务 | setting / family / decision；选择一个人物，解释一次决定 |
| Auld Lang Syne | 为什么人们在新年唱一首回忆旧友的歌？ | 苏格兰与新年文化卡；古老标题与现代英语含义对照；情感词云 | friendship / memory / celebrate；写一张三句英文新年卡。听教师提供的合法音源，不以完整歌词记忆为目标 |
| The Secret Garden | 一个花园怎样改变人物？ | Mary 的变化前后卡；人物关系图；花园意象与情绪配对；可折叠词汇提示 | lonely / curious / care / change；用 because / at first / later 写人物变化 |

## 推荐先做：California & Los Angeles

教学顺序：先问“LA is a city or a state?” → 看三级地名图 → 阅读约 150 词短文 → 做四道理解题 → 写一张目的地介绍卡。

参考知识点：California 是美国的州；Los Angeles 是该州的一座城市，简称 LA；Sacramento 是 California 的首府；Hollywood 是 Los Angeles 的一个街区。不要把 LA 说成州或州府，也不要把 Hollywood 当作独立州。

配套可直接上传的 HTML：`california-los-angeles.html`。该示例是原创教学文本，不依赖外部图片或脚本。页面有原生折叠提示，适合现有 HTML 展示器。

理解检测建议：
1. What is California? → A state.
2. What does LA stand for? → Los Angeles.
3. What is the capital of California? → Sacramento.
4. Is Hollywood a separate state? → No, it is a neighborhood in Los Angeles.

表达任务：Choose a place you know. Write four sentences: its name, where it is, one thing it is known for, and why you would like to visit it. 提供句架：It is in… / It is known for… / I would like to… because…

## 内容制作规范

- 一屏一个问题；英文短段落配必要中文支架，重点词控制在 6–8 个。
- 城市用层级图、地标卡、路线和比较表；电影用人物与事件；歌曲用情绪、文化与声音观察；小说用人物变化、因果和观点。
- HTML 支持排版、图片、表格、SVG 和 details/summary 折叠；现有展示器不执行 JavaScript，也不嵌入外站播放器。需要自动记录成绩时，使用 Culture Lab 的检测与表达字段。
- 官方旅游局、城市/州政府、博物馆、作品出版机构可作为备课来源。电影片段、歌曲录音、海报、译文与现代版本分别核对使用授权；不把“经典”视为自动可复制全文。
- 每篇末尾标明内容来源、图片来源和教师改编说明，事实与电影虚构分开。
- 本轮只提供内容方案和 HTML 示例，不会自动发布给学生或改动现有课程。
