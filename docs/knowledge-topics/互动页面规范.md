# 知识拓展互动页面规范

知识拓展的 HTML 有两种类型，在编辑器的“页面类型”中选择：

| | 静态页面 | 互动页面 |
|---|---|---|
| 脚本 | 全部移除 | 可以运行 |
| 大小上限 | 120KB | 1MB |
| 图片 | https 外链或内嵌 data URI | 同左，另外可用“页面媒体” |
| 音频、视频 | 不支持 | 上传到“页面媒体”后引用 |
| B 站视频 | 不支持 | 用 `data-bilibili` 嵌入 |
| 夜间模式 | 平台强制改色 | 页面自己定义配色 |
| 作为作业时划线批注 | 支持 | 不支持 |

上传含 `<script>` 的文件时，编辑器会自动切换为互动页面。

## 为什么互动页面在沙箱里运行

页面放在一个没有本站身份的 iframe 里（`sandbox="allow-scripts"`，不加 `allow-same-origin`），并且禁止页面发出任何网络请求。页面脚本因此：

- 读不到登录 Cookie，也调用不了 `/api`，不能以教师或学生身份修改数据；
- 访问不了外层页面；
- 加载不了外部脚本、字体、统计代码。这也让页面在国内网络下能完整打开。

页面需要的东西都由平台通过消息提供：当前主题、页面媒体，以及记录学习活动。

## 写页面的规则

1. **所有代码写在一个 HTML 文件里。** 不要用 `<script src>`、CDN、Google Fonts、`<link rel="stylesheet">`。需要库时，把用到的代码直接写进页面。
2. **不要联网。** `fetch`、`XMLHttpRequest`、`WebSocket` 都会被阻止。页面数据直接写在脚本里。
3. **图片、音频、视频放到“页面媒体”。** 上传时取一个名称（小写字母、数字、连字符，比如 `la-skyline`），然后在页面里写：
   ```html
   <img data-media="la-skyline" alt="Los Angeles skyline">
   <audio data-media="song-clip" controls></audio>
   <video data-media="film-clip" controls playsinline></video>
   ```
   平台会在学生登录后加载文件，填到 `src` 中。加载失败时，元素会带上 `data-media-error` 属性，可以用 CSS 隐藏。媒体文件会整份加载到浏览器，视频片段建议控制在 30MB 以内。
4. **夜间模式用 `html.dark`。** 平台会给 `<html>` 加上 `dark` 或 `light` 类，切换时页面不会刷新，学生的互动进度不会丢。推荐像模板一样把颜色写成 CSS 变量：
   ```css
   :root{--bg:#faf8f3;--ink:#22304a}
   html.dark{--bg:#111827;--ink:#e6eaf2}
   ```
5. **不要用 `100vh` 设置高度。** 平台会按内容自动调整 iframe 高度；按视口高度布局会让高度不断变大。
6. **可以用 `localStorage`，但只在本次打开期间有效。** 关闭页面后会清空，不要用它保存重要内容。
7. **表单不会提交。** 交互用按钮加脚本处理。需要保存的正式写作，请放到 Culture Lab 的“表达”步骤。
8. **B 站视频用 `data-bilibili`，不要自己写 iframe。** 详见下一节。
9. **来源与版权。** 页面末尾注明内容来源、图片和音视频的来源与授权；歌曲、电影只用有授权的片段，不放完整歌词或长片段。

## 嵌入 B 站视频

在页面中想显示视频的位置写一个占位元素：

```html
<div data-bilibili="BV1xx411c7mD"></div>
<!-- 也可以直接粘贴视频页地址；data-p 指定分 P，data-t 指定从第几秒开始 -->
<div data-bilibili="https://www.bilibili.com/video/BV1xx411c7mD" data-p="2" data-t="30"></div>
```

编辑器的“B 站视频”框可以把链接转换成这段代码。b23.tv 短链接无法识别，请在浏览器打开后复制地址栏中的完整地址。

工作方式：占位元素默认是 16:9 的黑色区域（可以用 CSS 改宽度）。平台把 B 站官方播放器放在占位处，学生在页面里直接点击播放，不跳转。播放器运行在 B 站自己的环境中，不在页面沙箱里，所以页面脚本控制不了它。平台会要求播放器不自动播放、关闭弹幕（以 B 站播放器实际支持为准）。

需要注意：

- 视频由 B 站提供，学生观看时浏览器会连接 B 站；原视频下架或设为私密后，页面上就看不了了。播放结束后可能显示 B 站的推荐内容。
- 页面无法知道学生是否看完。学生点击播放器时，占位元素会收到 `englishdaily:video` 事件，可以用来记录“看过视频”：
  ```js
  document.addEventListener('englishdaily:video', function (e) { ED.done('video'); });
  ```
- 放在折叠内容（如 `<details>`）里的视频，展开后才会显示。不要让页面里的其他元素（浮动按钮、弹窗）盖住视频位置，播放器总是显示在最上层。
- 只嵌入公开、适合学生观看的视频，并在页面末尾注明视频来源（UP 主、BV 号）。

## 平台提供的接口

页面里可以直接使用 `window.EnglishDaily`。为了让文件在本地用浏览器打开也能预览，建议这样写：

```js
var ED = window.EnglishDaily || { done: function(){}, media: function(){ return Promise.reject(); }, onTheme: function(){} };
```

| 接口 | 作用 |
|---|---|
| `ED.done('map')` | 记录学生完成了一个活动（名称最长 60 字符，同一页面同名只记一次）。学生端标题下显示“本页互动 · 已完成 N 项”；教师预览时会弹出提示，方便检查是否接好。 |
| `ED.media('la-skyline')` | 返回 Promise，得到可以直接用作 `src` 的地址。适合按需加载，比如点到某个城市时才显示照片。 |
| `ED.theme` | 当前主题：`'light'` 或 `'dark'`。 |
| `ED.onTheme(fn)` | 主题切换时调用 `fn('dark')`。例如画布或图表需要重新绘制时使用。 |

建议每个页面设置 3–5 个有意义的活动名称，例如 `big-question`、`map`、`quiz`、`order`、`express`。记录下来的活动会作为后续“探索收集”的依据。

## 发布前检查

编辑器会自动提示常见问题：外部脚本或字体、联网代码、iframe、http 图片、音视频外链、表单、`100vh`、缺少夜间样式、找不到的 `data-media` 名称、无法识别的 B 站地址。这些提示不是安全检查（安全由沙箱保证），只是帮助页面在学生端正常显示。

发布前请再自己检查：

- [ ] 在预览中把每个活动做一遍，确认 `ED.done` 的提示都出现了；
- [ ] 切换一次夜间模式，确认文字都看得清；
- [ ] 用手机宽度看一遍（约 390px），按钮能点、没有横向滚动；
- [ ] 核对事实、电影情节与真实历史分开写，注明来源和授权。

## 用 AI 生成页面的提示词

把下面这段连同 `interactive-template.html` 的完整内容一起发给 AI，再替换方括号里的内容：

```text
你是一名初中英语老师，正在为一名初三学生（英语 A2–B1 水平）制作一个英语文化探索网页。

主题：[例如 The Beatles / NBA / Auld Lang Syne / Mercedes-Benz]
核心问题：[一个能引起好奇的问题，例如 Why is "Hey Jude" still popular?]
学习时长：约 [20] 分钟
重点词汇（6–8 个）：[可以留空，让 AI 推荐]
我会上传的媒体（名称 → 内容）：[例如 cover-image → 乐队照片；song-clip → 30 秒歌曲片段；没有就写“无”]
B 站视频（BV 号 → 内容）：[例如 BV1xx411c7mD → 官方 MV；没有就写“无”]

请在我提供的模板基础上，输出一个完整的单文件 HTML：
1. 结构：大问题与猜测 → 3–5 张事实卡 → 一段 120–180 词的短文（重点词可点击查看中文意思） → 2–3 个互动活动（从选择题、排序、配对、地图点选、时间轴中挑最适合主题的） → 一个用句架写 2–3 句话的表达任务。
2. 英文简单清楚，句子短；每部分有一行中文提示，但不要整段翻译。
3. 所有 CSS 和 JavaScript 都写在文件内；不要引用任何外部脚本、字体、图片链接或 CDN；不要使用 fetch。
4. 图片、音频、视频只用 data-media="名称" 引用我列出的媒体，不要使用其他图片地址。B 站视频只用 <div data-bilibili="BV号"></div> 嵌入我列出的视频，不要写 iframe；学生点击视频时记录 ED.done('video')（监听 englishdaily:video 事件）。
5. 保留模板的 CSS 变量和 html.dark 夜间配色；不要用 100vh。
6. 每完成一个活动调用 ED.done('英文活动名')，并保留模板开头 ED 的写法。
7. 手机宽度 390px 下也要好用。
8. 只写你确定的事实；电影或歌曲内容与真实历史要分开说明；页面末尾写来源说明，留出我填写授权信息的位置。
```

拿到页面后，先在编辑器预览中做一遍，再逐条核对事实和来源。
